# DLG-GNN Benchmark v1.0.0-preprint

Paper: **A Reproducible and Scalability-Aware Benchmark for Graph Anomaly Detection with Decoupled Local-to-Global GNNs**

This release provides the public reproduction package for the frozen ten-dataset benchmark, LANL-RedTeam external validation, 45 sensitivity-control runs, exact-sparse reconstruction, and fused sparse message passing. It includes 71 exactly supported model–dataset cells (355 five-seed runs); the nine restrictions remain explicit and are not imputed.

Mode 1 regenerates publication tables without raw datasets. Mode 2 exposes the frozen full-execution protocol. Third-party raw datasets are not redistributed.
