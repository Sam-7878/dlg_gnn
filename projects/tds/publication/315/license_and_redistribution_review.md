# License and redistribution review

Review date: 2026-10-29. Upstream [GoG LICENSE](https://github.com/Xtra-Computing/Cryptocurrency-Graphs-of-graphs/blob/main/LICENSE)
specifies Attribution-NonCommercial-ShareAlike 4.0 International. The corresponding
license text is included verbatim in the candidate. The repository's existing
MIT software license is also included, without relicensing upstream data.

| Asset | Candidate policy |
|---|---|
| Research code and tests | Include attributed sources; preserve original hashes and list portability changes |
| Labels and score vectors, numeric tables | Candidate only; retain upstream attribution and NC-SA notice; author must confirm redistribution scope |
| Raw chain transaction ZIPs and labels.csv | Exclude; link upstream distribution and record hashes |
| Packed graphs and checkpoints | Exclude while redistribution scope remains unconfirmed |
| Unsubmitted manuscript, figures, source ZIP and manuscript writers | Keep author-local under the user's explicit privacy instruction |
| Private author records, local drives, secrets | Exclude; scan candidate payloads before packaging |

No conclusion that the numeric derivative is exempt from upstream terms is made.
MDPI publication licensing does not authorize blanket CC BY relicensing of GoG
artifacts. No legal clearance or author redistribution approval is fabricated.
If public redistribution remains unavailable, document controlled access with
the corresponding author and obtain author/editor approval for that alternative.
