# Reproduction levels

| Level | Author-local 315 validation | Public candidate | Anonymous release |
|---|---|---|---|
| L0 full manuscript source build | Both source PDFs and fresh private ZIP compiled; see final build report | Excluded by explicit author privacy policy; not publicly reproducible | Not available |
| L1 processed artifact verification | Frozen graph and 88 primary file hashes checked; 20 primary and 35 supplemental checkpoint hashes checked | Hash-only identities supplied; graph/checkpoints excluded | Not available |
| L2 prediction/statistics replay | 65 test arrays aligned; seven mean/SD AP pairs; one full 10,000-replicate paired comparison replayed | Runnable CPU commands and numeric files supplied, with eight invariant tests | Pending actual immutable deposition and anonymous download |
| L3 full GPU retraining / upstream reconstruction | Not run by 315 | Optional manual orchestration only; historical derivative inputs not bundled; no turnkey full rebuild claim | Not verified |

These are separate assertions. Local PASS is not anonymous reproducibility.
The full original seven statistical protocols were recomputed in R314; 315 checks
their source identities and Holm values and reruns one original comparison, not
all seven. The six exploratory contrasts remain separately identified. No claim
of reproducing missing historical epoch trajectories or independent prospective
sampling is made. Publication of the numeric subset requires license approval.
An editor/author must accept any private-source availability alternative before
closing the publication gate; that approval has not been assumed.
