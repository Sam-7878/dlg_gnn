# TDS R319 numerical evidence candidate

The experiment was preregistered in `protocol_freeze_319.json` before new test evaluation. `baseline_freeze_319.json` preserves R314–R318 identities. The independent builder receipt `seven_day_builder_equivalence.json` records exact source-to-tensor matches for 24,316 original and 24,179 seven-day graphs. Numeric CSVs report cutoff-admissible counts separately from the **retrospective full-archive span oracle**.

`runs/horizon7` contains five-seed neural run metrics, full epoch histories and validation/test score CSVs; checkpoints remain private. `predictions` contains deterministic controls and grid-selected LightGBM scores. `new_statistics_319.csv` is a separate exploratory four-comparison family and does not modify the preserved R317 statistical families.

This directory is a local publication candidate, **not** proof of public release or redistribution permission. Contract-derived sample IDs, timestamps and prediction scores can remain linkable. GoG source data and trained checkpoints are excluded. See `reports/319/rights_release_status.md` and the original upstream license before any release.
