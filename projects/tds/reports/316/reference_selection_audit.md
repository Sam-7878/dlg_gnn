# Reference selection from the Benchmark bibliography

The A16 Preprints bibliography was used as a discovery list, not as authority for
scientific claims or bibliographic metadata. No Benchmark source was modified.
Only two directly relevant references were added, bringing cited references19→21.

| Reference | Primary verification | Why included / boundary |
|---|---|---|
| Tang et al., GADBench, NeurIPS2023 | [Official proceedings](https://proceedings.neurips.cc/paper_files/paper/2023/hash/5eaafd67434a4cfb1cf829722c65f184-Abstract-Datasets_and_Benchmarks.html), DOI10.52202/075280-1289 | Supports strong simple controls for supervised anomalous-node evaluation. Its static node task is explicitly distinguished from this contract-graph task; its model ranking is not transplanted. |
| Qiao et al., TKDE2025,37(9):5106–5126 | [Author arXiv v2](https://arxiv.org/abs/2409.09957v2), [publisher DOI](https://doi.org/10.1109/TKDE.2025.3581578); publisher-registered Crossref metadata in qiao_reference_verification.json | Supports separating graph instance types and learning settings. Used to position supervised risk screening, not to claim a new detector or review contribution. |

Existing GoG/Elliptic2/CARE-GNN, temporal-evaluation and calibration references
remain relevant and unchanged. The full existing bibliography entries are preserved;
the two additions have matching author/title/year and verified DOI metadata.
Unsupervised/one-class detector references were not bulk-added as implied evaluated
baselines. Sampling/scalability papers were not added as a new contribution, and
the unverified2026 items were not used merely to make the list newer or longer.
