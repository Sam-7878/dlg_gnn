# Data contract audit

The packed graph SHA-256 remains `067cbdd7d7c055da91dbed9c492ad5a099c35e178f718e53f9dfdabab908b1cd`.
The immutable unit is a token/contract-local graph at the maximum valid transaction timestamp. Upstream `labels.csv` joins one-to-one on `(Chain, Contract)` for all 24,316 graphs. `Category == 0` maps to positive fraud; other categories map to the negative class under the upstream semantics. These are contract labels, not independently annotated transaction labels. Neither label discovery times nor a point-in-time fraud registry release are available; this is a retrospective-label classification benchmark, not proven prospective early warning.

The source builder first computes three log-degree features over the full observed contract history through the cutoff. It then retains at most 128 recent edges and the features of their endpoint nodes. The information set therefore includes summary history older than the retained topology. A model using this feature set is not described as reading only 128 transactions. The simple tabular controls include both retained-topology degree summaries and full-history input-feature summaries, with train-only scaling.

The frozen sample order is `(timestamp, sample_id)`. On-chain block numbers are available, but transaction index is absent. Source sorting includes timestamp, block number, transaction hash and original row index; the latter two do not establish physical intra-block precedence. Inclusive snapshots represent completed observation windows, permitting all transactions at the cutoff. Strict `edge timestamp < cutoff` is tested as an explicitly different information set. The packed payload retains only a maximum edge time; independent strict sensitivity reconstructs source rows, including degree features, rather than merely dropping edges while retaining contemporaneous features.

`data/timestamp_tie_audit.csv` reports 22,026 distinct cutoffs, 1,620 tied cutoffs, 3,910 participating samples and at most 13 samples at one timestamp. Chain-specific statistics are included.

The terminal test window is **2024-02-29 05:02:49 to 23:59:59 UTC**, elapsed 68,230 seconds (18 h 57 min 10 s). It contains 107 positives among 3,648 contracts. Ethereum/BSC/Polygon test counts are 1,469/1,491/688, with 68/38/1 positives. Polygon-only test inference is consequently not supported. The chain mixture changes, and prevalence declines within each chain as well; mixture alone does not explain the shift. Raw times, elapsed durations, split and six-bin chain breakdowns are in `data/split_composition.csv`.

Chain-qualified contract identities are disjoint across all splits, including the 107 positive test contracts. Raw hexadecimal addresses can coincide across different chains: 30 overlap between train/test and 36 between validation/test. Cross-chain identical hex strings are not assumed to denote the same contract. The packed graph does not retain sender/receiver address identities; contract-disjointness does not imply wallet-disjointness. No claim of independent address-level induction is made.

TGN source audit: `initial_memory` returns one zero state per chain; each phase starts with fresh memory. `forward_event` emits a logit from the current summary and previous memory, then builds the next state from current summary, time and previous memory. Validation/test use `no_grad`; labels are absent from memory updates. We call this within-partition predict-then-update stateful inference, without gradient adaptation or warm-start across split boundaries.
