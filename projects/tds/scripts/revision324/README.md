# R324 TDS manuscript revision (text and presentation only; no new experiments)

Sources live in the author-local tree `paper/submission_324/`:
`common/` holds every shared file (body, tables, figures, bibliography, Supplement),
`venues/{preprints,applsci}/` hold only the template wrappers.

- `build.py [--final]` builds the Supplement first (to number its tables), writes
  `common/supplement_refs.tex` so the article cites Supplement tables via `\STab{label}`,
  then builds both venues, fails on overfull boxes or undefined references, checks that
  the shared files are byte-identical in both venues, and writes PDFs, source ZIPs and
  `metadata.json` to `submission/{venue}/324/`. `--final` refuses while the DOI placeholder
  remains. PDF dates are fixed by `SOURCE_DATE_EPOCH` in the script; update it for a new freeze.
- `qa.py` checks the R324 work-order completion criteria and cross-checks key numbers against
  `results/323` and `results/319`; it writes `reports/324/qa.json`.
- Figure 1 is generated by `paper/submission_324/common/figures/fig_study_design.py`.

Release fields (DOI, licences, repository URL) are macros in `common/replay_reference.tex`.
