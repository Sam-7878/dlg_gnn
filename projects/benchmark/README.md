# Benchmark v2 evidence and reproduction

The frozen evidence contains **13 primary datasets**, seven functioning inferential models, **80/91** supported primary pairs and **435** approved primary/external successful records. CONAD is diagnostic only. BitcoinOTC uses controlled node anomaly injection on a real trust graph. Historical S1–S4 populations remain unchanged; three contract graphs have unresolved construction provenance and must not be described as cleared unsupervised fraud datasets.

## Reproduction modes

1. `./projects/benchmark/reproduce.sh verify` checks the public numeric ZIP’s **641** payload hashes, support/run counts, archived numerical qualifications, supplementary evidence hashes and a tiny independent Gram identity. Standard Python suffices; no GPU or raw provider data is required.
2. `./projects/benchmark/reproduce.sh tables` performs verification and regenerates frozen numeric tables plus seeded Friedman permutation statistics (200,000 permutations/view). NumPy and SciPy are required. Outputs: `evidence/astra_revision/`. No manuscript or training is involved.
3. `paper` is author-local only: unsubmitted TeX/Bib/PDF, A06 manuscript input and manuscript writers are intentionally excluded from Git. Missing private inputs yield an explicit message. It is not a public checkout reproduction promise.
4. `full` is a guard for manual campaign orchestration. It exits without training. Full neural reruns need source data, appropriate permissions, GPUs and campaign-specific environments; construction provenance remains incomplete for the three crypto graphs.

Use `.venv_cuda` for local scientific work. CI uses standard Python for integrity, without claiming neural retraining. See [data and construction](DATASETS.md), [environment provenance](ENVIRONMENT.md), [revision audit](reports/astra_revision/README.md) and [checkout verification](FRESH_CLONE_VERIFICATION.md).

## Public evidence versus private originals

`evidence/public_numeric_evidence.zip` is a publication derivative of the local immutable A05/A06 ZIP. It removes four manuscript-writing/packaging scripts and retains all other payload bytes unchanged. Its manifest records original archive hash, excluded paths and every retained payload hash. `expected_outputs.json` records both archive identities. A measured-memory figure PDF inside this evidence ZIP is supporting evidence, not the manuscript PDF.
